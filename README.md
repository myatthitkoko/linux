# Linux System Health Report

This repository is a collection of my bash files and labs from previous college courseworks in Unix/Linux.

sysCheck.sh file is the most recent creation that tracks CPU, memory, and disk usage. It automatically generates log files every 5 minutes while the Codespace remains active.
